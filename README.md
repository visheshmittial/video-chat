Video Chat
A real-time video chat application built using React, Node.js, Socket.IO, and WebRTC. The application enables users to make peer-to-peer video calls and exchange live messages with low latency and smooth communication.

# Features
Real-time peer-to-peer video calling using WebRTC
Live text chat with Socket.IO
Responsive and interactive user interface
Fast communication with low latency
Multi-user connection handling through signaling server

# Installation & Running
Clone the Repository
git clone https://github.com/visheshmittal/video-chat.git
cd video-chat
# Install Backend Dependencies
cd backend
npm install
npm start
# Install Frontend Dependencies
cd ../frontend
npm install
npm start
Open in Browser
http://localhost:3000
