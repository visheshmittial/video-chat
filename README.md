Video Chat

A real-time video chat application using React, Node.js, Socket.IO, and WebRTC. While primarily a full-stack project, I applied QA concepts such as manual functional testing, API validation, and regression testing to ensure system reliability during development.

Features Tested / QA Perspective

Peer-to-peer video calls via WebRTC tested for connectivity and stability.

Live text chat system tested for message delivery accuracy and performance under load.

User interface tested for responsiveness and correct interaction flows.

Tech Stack

Frontend: ReactJS (JavaScript, HTML, CSS)

Backend: Node.js, Express.js, Socket.IO

Peer Connection: WebRTC

Other Tools: npm, React Scripts, STUN Servers

Installation & Running
# Clone the repository
git clone https://github.com/visheshmittal/video-chat.git
cd video-chat

# Install backend dependencies
cd backend
npm install
npm start

# Install frontend dependencies
cd ../frontend
npm install
npm start

# Open in browser
Open http://localhost:3000
